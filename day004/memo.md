# Day 004 — コインフリッパー

## 今日作ったもの
ボタン（またはSpace/Enter）を押すとコインが3Dアニメーションで跳び上がり、表・裏をランダムに判定するアプリ。投げた回数・表率もリアルタイム集計。

## うまくいったこと
- CSS `transform-style: preserve-3d` と `backface-visibility: hidden` で本物らしい3Dコインを実現
- ラッパー要素（縦バウンス）とコイン要素（Y軸回転）を分離することで、2つのトランスフォームを干渉させずに合成できた
- 角度を累積する方式（`totalAngle += delta`）でフリップを繰り返しても正しい面が出る計算がすっきり書けた

## 詰まったこと・学び
- `transform` は1つの要素に1つしか指定できないので、バウンスと回転を同じ要素に両方かけると上書きされてしまう → 親子要素に役割を分けて解決
- `rotateY(0)` が表、`rotateY(180deg)` が裏になるよう余り(mod 360)から delta を計算する必要があった
- アニメーション終了タイミングを `animationend` でなく `setTimeout` で取ると、再フリップ時のイベント多重登録バグを避けられた
