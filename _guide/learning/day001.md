# Day 001 — 今日の学び

## Git の基本コマンド

| コマンド | 意味 |
|----------|------|
| `git init` | フォルダをGit管理できるようにする |
| `git add .` | 全ファイルを「次のコミット対象」に選択 |
| `git commit -m "メッセージ"` | セーブポイントを作る |
| `git branch -M main` | ブランチ名を `main` に設定 |
| `git remote add origin URL` | GitHubリポジトリと紐づける |
| `git push -u origin main` | GitHubにアップロード |

## GitHub Pages とは
GitHubに置いたHTMLをそのままウェブサイトとして無料公開できるサービス。

```
PC（ローカル）
  ↓ git push
GitHub（リポジトリ）
  ↓ Pages が自動変換
https://N-3785.github.io/100days-app/（公開URL）
```

Settings → Pages → Branch を `main` に設定するだけで有効になる。

## Google Analytics とは
ウェブサイトのアクセス数・訪問者の動きを無料で計測できるGoogleのサービス。
HTMLの `<head>` にトラッキングコードを貼るだけで設置できる。

## 毎日の公開コマンド

```powershell
cd "C:\dev\100days-app"

```
